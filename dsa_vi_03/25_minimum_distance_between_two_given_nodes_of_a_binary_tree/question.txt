Khoảng cách ngắn nhất giữa hai node đã cho của cây nhị phân
Cho một cây nhị phân (binary tree) với n node và hai giá trị node, a và b, nhiệm vụ của bạn là tìm khoảng cách ngắn nhất giữa chúng. Hai node đã cho được đảm bảo nằm trong cây nhị phân và tất cả các giá trị của node là duy nhất.

Ví dụ:
Đầu vào: Tree = [1, 2, 3]
        1
      /  \
     2    3
a = 2, b = 3
Đầu ra: 2
Giải thích: Chúng ta cần tìm khoảng cách giữa 2 và 3. Đang ở node 2, chúng ta cần đi hai bước về phía trước để tới node 3. Đường đi như sau: 2 -> 1 -> 3. Do đó, kết quả là 2. 
Đầu vào: Tree = [11, 22, 33, 44, 55, 66, 77]
        11
      /   \
     22  33
    /  \  /  \
  44 55 66 77
a = 77, b = 22
Đầu ra: 3
Giải thích: Chúng ta cần tìm khoảng cách giữa 77 và 22. Đang ở node 77, chúng ta cần đi ba bước về phía trước để tới node 22. Đường đi như sau: 77 -> 33 -> 11 -> 22. Do đó, kết quả là 3.

Đầu vào: Tree = [1, 2, 3]
        1
      /  \
     2    3
a = 1, b = 3
Đầu ra: 1
Ràng buộc:
2 <= số lượng node <= 105

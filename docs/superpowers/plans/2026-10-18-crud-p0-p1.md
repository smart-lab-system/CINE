# CRUD gaps P0 + P1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đóng các lỗ CRUD P0 (lớp học phần: UI unassign / sửa meta / đổi `nominalClassId`) và P1 (sửa tên enrollment; sửa phòng·giờ phiên trước freeze; huỷ phiên nháp; gỡ SV manual khỏi session roster) theo audit spec — không đụng grading pipeline hay catalog master data đã đủ CRUD.

**Architecture:** Wave A (P0) chủ yếu bắt API admin đã có + mở rộng PATCH `nominalClassId`. Wave B (P1.1) thêm PATCH enrollment trên cả admin và teacher roster. **Tech Stack:** NestJS 11 + TypeORM + PostgreSQL 16 (`examcollect`), Jest/supertest e2e; Next.js App Router + TanStack Query + shadcn; `openapi-typescript` (`@cine/shared generate:api-client`).

- Admin lớp HP: `POST/GET/PATCH/DELETE /admin/course-sections`, `POST …/assign`, `POST …/unassign` — `AdminCourseSectionController` / `AdminCourseSectionService`.
- `UpdateCourseSectionDto` hiện chỉ `courseId?` / `semesterId?` — **không** có `nominalClassId`.
- UI detail `apps/web/src/app/admin/course-sections/[id]/page.tsx`: assign + delete + roster; **không** unassign, **không** form sửa meta / lớp danh nghĩa.
- Web API client: `apps/web/src/lib/api/admin-course-sections.ts` — chưa có `unassign` / `update`; hooks `useAdminCourseSections.ts` thiếu tương ứng.
- Enrollment: `RosterService` add/import/remove; import đã cập nhật `studentName` khi trùng mssv; **không** có PATCH một dòng.
- `exam_session`: create ghi `status = 'active'` ngay (debt đã ghi trên entity); freeze roster = `POST …/open` → `SessionRosterService.freeze`. Guard “trước khi mở” = **chưa có dòng `session_roster`**, không dùng `status !== 'active'`.
- `ScheduleConflictService.assertNone(...)` **không** nhận `excludeSessionId` — comment đã cảnh báo reschedule sẽ tự-conflict; `findClash` cần thêm `AND s.id <> :excludeId`.
- Session roster: `POST …/roster/students` → `addManually` (`source=manual`); **không** có DELETE. `seedSeats` tạo submission chỗ ngồi khi thêm tay.
- Status enum đã có `cancelled` (exclusion / conflict bỏ qua `cancelled`). Soft-cancel giải phóng phòng mà không đụng RESTRICT FK con.
- E2E: `apps/api/test/admin-course-section.e2e-spec.ts`, `session-roster-freeze.e2e-spec.ts`, `exam-schedule-conflict.e2e-spec.ts`.
- OpenAPI: `API_URL=http://localhost:4000/api-docs-json pnpm --filter @cine/shared generate:api-client`.
- E2E chỉ `.env.test` → Postgres docker `localhost:5442`; cấm `apps/api/.env` cloud.
- Migration mới (nếu cần): timestamp **> `1789560000000`**. Wave A–C **không** cần migration schema nếu soft-cancel + PATCH cột đã có.

## Global constraints

- **Không** cascade đổi tên catalog → enrollment / session snapshot.
- **Không** đổi mssv qua PATCH enrollment (đổi mssv = xoá + thêm).
- **Không** cho đổi `semesterId` / `semesterName` sau tạo phiên (`semester_name` vẫn bất biến).
- **Không** xoá dòng `session_roster.source = 'frozen'`.
- **Không** đụng grading / agent protocol / archive-check ngoài cleanup submission chỗ ngồi khi gỡ manual (nếu có).
- Conflict check khi reschedule **bắt buộc** exclude chính phiên.
- Commit theo task khi được yêu cầu; không push/PR đến khi được bảo.

## Review focus

1. Unassign UI: 409 khi đã có phiên — không nuốt lỗi.
2. PATCH meta lớp: `assertMetaMutable` (roster trống + không phiên); đổi `nominalClassId` **không** yêu cầu mutable đó.
3. PATCH enrollment: chỉ `name`; resolve lại `student_id` optional theo mssv.
4. PATCH phiên: chỉ khi **chưa freeze**; dual-write `roomId` → `room_name`; conflict có `excludeSessionId`.
5. Huỷ phiên: soft `cancelled` (ưu tiên) với guard chưa freeze / chưa collected; hard DELETE chỉ nếu chọn làm thêm và cascade con an toàn.
6. Gỡ session roster: chỉ `manual` + chưa nộp thật; xoá chỗ ngồi `not_submitted`/`absent` nếu có.

**DTO (chỉ các field này):**

| Field | Rule |
|---|---|
| `roomId?` / `roomName?` | XOR-friendly như create; dual-write catalog |
| `startTime?` / `endTime?` | `end > start`; cả cặp hoặc một phía + giữ phía kia |

**Cấm:** `semesterId`, `semesterName`, `classId`, `rubricId` (rubric đã có route riêng), deliverables.

**Guard:**

1. Owner teacher.
2. `!isFrozen(session.id)` → nếu đã freeze: 409 “Đã chốt danh sách dự thi — không đổi phòng/giờ.”
3. Optional cứng hơn: không có submission `collected`/`validated` (phòng thủ).
4. Dual-write room → `assertNone(..., { excludeSessionId: session.id })`.
5. Không đụng `semester_*`.

- [ ] **Step 1:** DTO + service update.
